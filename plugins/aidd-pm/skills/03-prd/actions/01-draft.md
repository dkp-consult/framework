# 01 - Draft

Draft a PRD from the template, iterating with the user to approval.

## Input

A feature description, and optionally existing user stories.

## Process

1. Extract scope, goals, and constraints from the description and any user stories.
2. Draft [prd-template.md](../assets/prd-template.md), keeping every section concise and actionable.
3. Present the full draft and wait for explicit approval.
4. Fold corrections and re-show the updated draft until approved.
5. Read [finalize](02-finalize.md) with the approved draft unchanged.

## Output

One approved PRD draft.

## Rules

- The draft holds every section `prd-template.md` defines, and no other.
- The draft proposes no tech-stack, data-model, or architecture section, and no code.
