# 03 - Method

Pick the lightest collection that can settle each gap.

## Input

The ranked decisive gaps.

## Process

1. Apply [methods](../references/methods.md) to each gap.
2. Apply [practices](../references/practices.md) to each chosen method.
3. Give each method a stop condition and a collecting role.
4. Agree each gap's decision rule per `methods.md`, then wait for the user's confirmation.
5. Read [kit](04-kit.md).

## Output

One method per gap, with its stop condition, its decision rule, and the role that collects.

## Rules

- A collecting role is a role or a team, never a person's name.
