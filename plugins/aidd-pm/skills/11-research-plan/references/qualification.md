# Qualification

A gap is worth collecting only when its answer can change a named product decision.

| Situation | Result |
| --- | --- |
| No decision would change whatever the answer | discard |
| Already accepted by the user as a risk | discard, keep the acceptance |
| Settled by the user in the current exchange | record the answer as a decision, no collection |
| Several assumptions settled by one collection | one gap, every assumption listed |
| Otherwise | keep |
