# Practices

The team's product practices are the `po-practices` file of project memory, found where the memory block of the project's AI context file lists it, else at `aidd_docs/memory/po-practices.md`. It starts absent.

| Situation | Handling |
| --- | --- |
| file absent | use the defaults and the asset skeletons as they are |
| practice recorded for the method or kit | apply it over the default |
| practice contradicts a transversal rule | keep the rule, report the conflict |
| file absent, adaptation approved and kept | create the file from the [practices template](../assets/po-practices.md) with only `## Research` |
| file present, adaptation approved and kept | hand it to a learning capability with the before and after values |
| no adaptation kept | write nothing |

Never infer a practice from one run; only what the user approves is recorded.
