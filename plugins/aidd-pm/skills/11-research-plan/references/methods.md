# Methods

Take the lightest method that can settle the gap.

| Gap is about | Default method | Default stop condition | Kit asset |
| --- | --- | --- | --- |
| motivation, context, workaround | interviews | about five sessions, or two in a row add nothing new | [interview guide](../assets/interview-guide.md) |
| how many users share a pain or preference | survey | the sample the project accepts, or a stable answer split | [survey](../assets/survey.md) |
| behavior inside the product | analytics query or export | the period and segment named in the plan are covered | [export request](../assets/export-request.md) |
| reported pain | support review | the period named in the plan is read | `export-request.md` |
| conversion, churn, revenue | billing export | the period named in the plan is covered | `export-request.md` |
| buyer objections | sales notes review | the deals named in the plan are read | `export-request.md` |
| competitors and market offer | watchlist | every listed competitor is read once | [watchlist](../assets/watchlist.md) |

A gap matching no row takes the closest one, with the difference stated in the plan.

| Survey channel | Questions |
| --- | --- |
| native poll in a chat tool, such as Discord or Slack | one question per poll; the others go in a thread or a form |
| form or survey tool | every question in one form |

| Decision rule | Holds |
| --- | --- |
| continue | the result that keeps the assumption and the decision it gates |
| stop | the result that drops the idea or the option |
| reframe | the result that sends the assumption back to be restated |
| minimum sample | the fewest sessions, answers, or records under which no result counts |
| timing | fixed with the user before any collection starts; a change after results arrive is recorded in the plan with the user's reason |
