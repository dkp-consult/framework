# 03 - Visualize

Clarify a product relationship, journey, comparison, or screen structure when prose is weaker.

## Input

The current product understanding.

## Process

1. Apply [visuals](../references/visuals.md) to the current understanding.
   - No matching view: produce no `Product View`.
2. Present the visual and wait.
3. Fold user corrections into the visual.
4. Read [shape](04-shape.md) once the visual is accepted or skipped.

## Output

One optional table, Mermaid diagram, or low-fidelity wireframe.

## Rules

- A produced view uses exactly one format, passes its format and `Any view` contracts, and a Mermaid view parses.
