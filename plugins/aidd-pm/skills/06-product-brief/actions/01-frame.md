# 01 - Frame

Establish what product is being framed and where useful evidence can come from.

## Input

An idea, an existing product, or the current context.

## Process

1. Infer the product from current context.
   - Not identifiable: ask one open question for the idea, with no field list, and wait.
2. Apply [evidence](../references/evidence.md) to available sources.
   - Existing product: inspect relevant project evidence before asking what it answers.
3. State the opportunity.
   - The request is not one: apply [handoffs](../references/handoffs.md) and create no brief.
4. Ask about any ambiguity that could change it and wait.
5. Name only project inspection or external research that could resolve a live claim, each path with the claim it may change.
6. Read [discover](02-discover.md).

## Output

The product scope and evidence path.
