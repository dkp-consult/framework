# Handoffs

Offer the named capability with what was observed, then stop unless the row says the run continues. Never invoke it silently, never write outside a decision snapshot or the `## Prioritization` section of the practices.

| Observed | Capability | Return |
| --- | --- | --- |
| Stories under one parent to order | User Story | one-way; no score |
| decisive `unknown` the user wants collected first | Research plan | ranking resumes once the evidence is in an insights registry |
| no sources registry, collection wanted | Research plan | one-way |
| raw signals or a `done` plan not yet in an insights registry | a synthesis capability | the run continues without them |
| market pressure claimed without a market row | a market watch capability | the run continues with the criterion `unknown` |
| estimate missing on a project with a scale | the capability owning that artifact | the run continues with effort `unknown` |
| decided order differing from the current one | a backlog orchestration capability | receipts from each artifact owner |
| decided changes touching no order field | none | stated; the ranks stay in the snapshot |
| no backlog orchestration capability installed | none | the change set shown with each owner named |
| run offered by the capability owning that artifact | that capability | its paused step resumes with the snapshot path |
| no match | none | report what was observed |
