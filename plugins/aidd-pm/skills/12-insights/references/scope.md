# Scope

| Case | Read | Period | Assumptions to confront | Theme |
| --- | --- | --- | --- | --- |
| theme or product area | every declared source whose Can support covers the theme | the one the user names, else all available | those bearing on the theme | the area, in kebab-case |
| research plan | the sources its gaps name and the material it links | the plan's collection | the plan's gap assumptions | the area the plan is about |
| assumption | the declared sources able to support it | the one the user names, else all available | that assumption | the area it belongs to |
| since the last run | the sources recorded in `## Customer runs` of the theme | from each source's latest run date | those bearing on the theme | the existing theme |

| Situation | Handling |
| --- | --- |
| research plan `open` | say that collection has not started; ask whether to read anyway |
| research plan `cancelled` | say so and ask for another scope |
| since the last run, no run recorded | ask for the period |
| request outside this skill | offered per `handoffs.md` |
