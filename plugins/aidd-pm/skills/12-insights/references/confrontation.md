# Confrontation

Each artifact is read at its location per `persistence.md`.

| Artifact | Assumptions read |
| --- | --- |
| research plan | the Assumption column of its gaps |
| Product Brief | the assumptions it states |
| Epic | the assumptions behind its outcome and success evidence |

| Effect | When |
| --- | --- |
| `supports` | the insight agrees with the assumption |
| `contradicts` | the insight goes against the assumption |
| `new` | the insight bears on no recorded assumption |

| Situation | Handling |
| --- | --- |
| insight bearing on several assumptions | link each; `contradicts` when any is contradicted, that link marked `(contradicted)` |
| contradicted assumption | marked in the registry row only; its artifact stays as written |
| low confidence insight against an assumption | still `contradicts`; the confidence carries its weight |
| assumption settled by no insight | unresolved, offered per `handoffs.md` |
