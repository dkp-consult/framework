# Handoffs

Name the capability and what was observed, then stop. Nothing is invoked silently, and nothing is written outside the insights registry or a first practice.

| Observed | Capability | Return |
| --- | --- | --- |
| one opportunity to frame from the evidence | Product Brief | one-way; it reads the registry |
| competitors or market offer to follow | a market watch capability | one-way; no `customer` row |
| effect of a shipped change to measure | an impact capability | one-way |
| one need to turn into one backlog artifact | a backlog orchestration capability | one-way |
| unreadable source | its owner role | one-way; the export is read on a later run |
| no registry and no manual material | Research plan | one-way; run again once the registry exists |
| nothing in scope holds a signal | Research plan | one-way; the gap stated |
| low confidence insight or unresolved assumption | Research plan | one-way; the gap stated |
| scope was a research plan, its material now synthesized | Research plan | one-way; the plan moves to `done` there when the user asks |
| contradicted assumption from a Product Brief or an Epic | the capability owning that artifact | one-way; the artifact is revisited there |
| actionable insights to rank | a prioritization capability | one-way |
| actionable insights to turn into backlog work | a backlog orchestration capability | one-way |
| no match | none | report what was observed |
