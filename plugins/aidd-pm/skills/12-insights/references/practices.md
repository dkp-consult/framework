# Practices

The team's product practices are the `po-practices` file of project memory, found where the memory block of the project's AI context file lists it, else at `aidd_docs/memory/po-practices.md`. It starts absent. This skill reads and writes only its `## Insights` heading.

| Situation | Handling |
| --- | --- |
| file or heading absent | apply the defaults of `rating.md` |
| repetition threshold or segment definitions recorded | apply them over the defaults, to every registry row whatever its origin |
| practice contradicts a transversal rule | keep the rule, report the conflict |
| file absent, adaptation the user wants to keep | create the file from the [practices template](../assets/po-practices.md) holding only that adaptation |
| file present, adaptation the user wants to keep | hand it to a learning capability with its before and after values |
| no adaptation kept | write nothing |

Two conditions are outside any practice and outside this skill: the cap on a `market` row about a user need, and the baseline and decision rule a `measured` row needs to reach `high`.

A practice is recorded only when the user approves it; one run never implies one.
