# 01 - Scope

Settle what to read, over which period, and for which theme.

## Input

A theme or product area, a research plan by path, an assumption, or a request to read what arrived since the last run.

## Process

1. Identify the case and what it reads per [scope](../references/scope.md).
   - Nothing identifies the scope, or `scope.md` calls for an answer: ask one question, wait, and resolve again.
   - The request lies outside this skill: offer the capability [handoffs](../references/handoffs.md) names and stop.
2. Match the scope to an existing registry file per [persistence](../references/persistence.md), or propose a theme for the user to confirm.
   - Proposed theme declined: ask for another one and resolve again.
3. Show the theme, the sources, and the period in one line.
4. Read [gather](02-gather.md).

## Output

The scope: the theme, the sources to read, the period, and the assumptions to confront.

## Rules

- Scope reads no source and writes nothing.
