# 04 - Confront

Compare each insight with the assumptions already recorded.

## Input

The rated insights from 03 and the assumptions named by the scope.

## Process

1. List the assumptions bearing on the theme per [confrontation](../references/confrontation.md).
2. Give each insight one effect per `confrontation.md`.
3. List every assumption in scope that no insight settles.
4. Read [persist](05-persist.md).

## Output

Each insight with its effect and the assumptions it bears on, and the assumptions left unresolved.

## Rules

- Confront writes nothing.
