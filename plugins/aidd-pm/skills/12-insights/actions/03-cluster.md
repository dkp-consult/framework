# 03 - Cluster

Group the signals into a few rated insights.

## Input

The kept signals from 02.

## Process

1. Apply [practices](../references/practices.md) to the defaults of [rating](../references/rating.md), then any adaptation the user asks for in this run.
2. Merge the signals that state the same finding into one insight worded per `rating.md`.
3. Give each insight its frequency, segments, and confidence per `rating.md`.
4. Read [confront](04-confront.md).

## Output

The candidate insights, each with its signals, frequency, segments, and confidence, and any adaptation the user made to the defaults.

## Rules

- Cluster writes nothing.
