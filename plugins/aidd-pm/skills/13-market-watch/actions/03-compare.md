# 03 - Compare

Class what moved since the last read and keep the findings that matter.

## Input

The observations from scan, the previous observations, the themes, and the threshold from scope.

## Process

1. Class each observation against the competitor's previous observations per [comparison](../references/comparison.md).
   - Nothing new, changed, or removed: keep only the dated read lines, draft no insight, and report nothing new.
2. Apply the threshold per `comparison.md`.
3. Keep the findings that matter per `comparison.md`, each mapped to a theme.
4. Read each theme file and give each finding its confidence, effect, and links per [insights registry](../references/insights-registry.md).
5. Read [persist](04-persist.md).

## Output

Each observation classed `new`, `changed`, or `removed`, the market standards gained or lost, and each finding that matters with its theme, confidence, and effect; or nothing new.

## Rules

- Compare writes nothing.
